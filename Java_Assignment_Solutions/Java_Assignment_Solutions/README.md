# Java Assignment Solutions

This folder contains 21 independent Java programs covering the complete assignment.

## Requirements
- JDK 17 or later (JDK 26 is also fine)
- VS Code with the Java Extension Pack, or any Java IDE

## How to run
1. Extract the ZIP file.
2. Open the extracted `Java_Assignment_Solutions` folder in VS Code.
3. Open the required `.java` file.
4. Run it using the **Run Java** button, or use the terminal:

```bash
javac FileName.java
java FileName
```

Each program is independent. Compile and run one file at a time. The filename and public class name match.

## GitHub submission
1. Sign in to GitHub and create a **New repository** (for example, `Java-Assignment-Solutions`).
2. Extract this ZIP on your computer.
3. Open the repository page and choose **Add file → Upload files**.
4. Upload the contents of the extracted folder (including this README), then click **Commit changes**.
5. Copy your repository URL and paste it into the assignment submission section.

Example repository URL format:
`https://github.com/your-username/Java-Assignment-Solutions`

Do not submit the example URL; use the actual URL of your own repository.
